# Changelog

## 0.1.0-preview

- Added an Electron + React + TypeScript Windows desktop shell.
- Added local profile metadata management and appearance settings.
- Added official Minecraft Launcher hand-off; NIVA does not implement account authentication.
- Added Windows NSIS and portable EXE packaging workflow with SHA-256 checks.
- Added profile validation unit tests.

This preview does not yet install Minecraft, Java, loaders, or mods.
